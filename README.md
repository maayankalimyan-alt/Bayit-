# הבית שלנו - הוראות התקנה

## 1. Supabase
1. SQL Editor ← New query ← מדביקים את כל `schema.sql` ← Run.
2. Authentication ← Sign In / Providers ← Email ← מכבים Confirm email ← Save.
3. מעתיקים את Project URL ואת המפתח anon public.

## 2. הגדרות
פותחים את `config.js` ומדביקים את שני הערכים בין המירכאות.

## 3. GitHub Pages
1. github.com ← New repository ← שם: `bayit` ← Public ← Create.
2. Add file ← Upload files ← גוררים את כל הקבצים והתיקייה icons ← Commit.
3. Settings ← Pages ← Branch: `main` ← Save ← מחכים דקה.
4. הכתובת: `https://<שם-המשתמש>.github.io/bayit/`

## 4. בטלפון
- אייפון: Safari ← שיתוף ← הוסף למסך הבית.
- אנדרואיד: Chrome ← ⋮ ← התקנת אפליקציה.

## 5. התחברות
1. מעיין נרשמת ← "בית חדש".
2. הגדרות ← קוד הזמנה ← שיתוף לריחן.
3. ריחן נרשם ← "יש לי קוד הזמנה".
